# Cleanroom Design Contract

## Product
A private, local-first Streamlit utility for removing Gemini-style sparkle marks from images and videos. The UI belongs to Developeros and intentionally avoids the original site's marketing, SEO, ad, and cross-promotion surfaces.

## Visual direction
- Darkroom-inspired workbench: deep forest-black canvas, moss panels, acid-lime action color, coral reserved for warnings.
- Typography: Manrope for interface text and DM Mono for labels, measurements, and status readouts.
- Geometry: compact 8px panels, 5px controls, thin green-gray rules, no decorative cards nested inside cards.
- Layout: wide desktop workspace with a narrow configuration rail and an upload/result bench; single-column mobile collapse.

## Interaction contract
1. Load one image or video.
2. Adjust gain, mask scale, video alignment, and video method.
3. Process locally.
4. Inspect source and clean result.
5. Download PNG or MP4.

## Exclusions
No browser JavaScript engine, GitHub star counter, external ads, donation widget, unrelated image converter, SEO copy, or personal links from the inherited site.
